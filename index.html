Как добавить ещё один сайт

Файлы можно хранить рядом с этой страницей — например в папке sites/. Дальше просто вписываешь сайт в список ниже.

01

Положи файл рядом

Например: sites/portfolio.html в той же папке, что и этот index.html.

02

Открой index.html в редакторе

Найди массив SITES внизу файла — прямо перед закрывающим тегом </script>.

03

Добавь строку и сохрани

Карточка появится автоматически при открытии страницы — писать HTML руками не нужно.

// внутри массива SITES добавь объект такого вида:
{
  name: "Название сайта",
  description: "Коротко, о чём этот сайт",
  url: "sites/moy-sayt.html",
  tags: ["проект"]
}
сделано на чистом HTML · открывай в любом браузере · хостится где угодно
